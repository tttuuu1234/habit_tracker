GitHub Issueを日本語で作成してください。

## 手順

### 1. Issueの種類を選択
- まず最初に `AskUserQuestion` ツールを使って、Issueの種類を選択式で確認する
- 選択肢:
  - **feat**: 新機能の追加
  - **fix**: バグの修正
  - **improve**: 既存機能の改善・リファクタリング
  - **chore**: ドキュメント・CI・依存関係などのメンテナンス
- 選択された種類に応じてIssueのタイトルにプレフィックスを付与する（例: `[feat] 習慣のリマインダー通知機能`）

### 2. 要件の確認
- 引数 `$ARGUMENTS` が指定されている場合はそれを元に内容を把握する
- 引数がない場合や情報が不足している場合はユーザーに質問して要件を明確にする

### 2. コードベースの調査（必要に応じて）
- 関連する既存コードやissueを確認する
- `gh issue list` で既存のissueと重複がないか確認する

### 3. Issueの作成
- タイトルと本文を作成し、ユーザーに確認を取る
- 承認後 `gh issue create` でissueを作成する

## Issueのフォーマット

タイトル: 簡潔な日本語

本文:
```markdown
## 概要
<!-- 何を実現したいかを1-3文で説明 -->

## 背景・動機
<!-- なぜこの変更が必要かを説明 -->

## 要件
<!-- 具体的な要件を箇条書きで -->
- [ ] 要件1
- [ ] 要件2

## 補足
<!-- 参考情報、技術的な制約、関連issueなど -->
```

## 注意事項

- 引数やユーザーの指示が曖昧な場合は必ず質問して要件を明確にする
- issueの内容はユーザーに提示し、承認を得てから作成する
- 適切なラベルがあれば `--label` で付与する
