現在のブランチの変更内容を分析し、日本語でPull Requestを作成してください。

## 手順

1. `git branch --show-current` で現在のブランチ名を確認する
2. `git log main..HEAD --oneline` でmainブランチからの全コミットを確認する
3. `git diff main...HEAD` で変更差分の全体像を把握する
4. `git status` で未コミットの変更がないか確認する（あれば警告する）
5. リモートブランチにpushされているか確認し、必要ならpushする
6. 変更内容を分析してPRのタイトルと本文を作成する
7. `gh pr create` でPRを作成する

## PRのフォーマット

タイトル: 簡潔な日本語（70文字以内）

本文:
```markdown
## 概要
<!-- 変更の目的と背景を1-3文で説明 -->

## 変更内容
<!-- 主な変更点を箇条書きで -->

## テスト計画
<!-- テスト方法・確認項目をチェックリストで -->
- [ ] テスト項目1
- [ ] テスト項目2

## スクリーンショット
<!-- UI変更がある場合のみ -->
```

## 注意事項

- mainブランチ上にいる場合はPR作成を中止し、先にブランチを作成するよう案内する
- 未コミットの変更がある場合は先にコミットするか確認する
- PRのタイトルはコミット履歴全体を要約したものにする（個別コミットのコピーにしない）
- 変更内容セクションではユーザーが理解しやすいように機能単位でまとめる
