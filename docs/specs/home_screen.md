# ホーム画面 仕様書

## 1. 概要

ホーム画面はアプリ起動時に最初に表示される画面であり、ユーザーが登録した習慣の一覧と本日の達成状況を確認できる。

主な目的:

- 本日の習慣一覧を表示する
- 各習慣の達成状況（完了/未完了）を一目で把握できるようにする
- 達成操作を素早く行えるようにする

## 2. 表示仕様

### 2.1 ヘッダー

- **日付**: 当日の日付を「M月d日 曜日」形式で表示する（例: 8月14日 木曜日）
- **挨拶メッセージ**: 「お疲れさまです」を固定表示する

### 2.2 進捗リング

達成済み習慣の割合を円形プログレスバーで可視化する。

- リング中央に「達成数/全体数」と「完了」のテキストを表示する
- 12時方向を起点に時計回りで進捗率を描画する
- 習慣が0件の場合、進捗率は0%として表示する

### 2.3 習慣リスト

登録された習慣をカード形式のリストで表示する。各項目は以下の情報を含む。

- **達成アイコン**: 未達成は空の円、達成済みはチェックマーク付きの塗りつぶし円
- **習慣名**: 習慣の名称
- **連続日数**: 連続達成日数を「X日」形式で表示する。達成済みの場合はバッジ表示、未達成の場合はプレーンテキスト表示

## 3. ユーザー操作

### 3.1 習慣をタップ

- 習慣の詳細画面へ遷移する（別issueで対応予定）

### 3.2 習慣をロングプレス

- **未達成の習慣のみ**が対象。達成済みの習慣では何も起きない
- ロングプレスすると達成確認ダイアログを表示する

### 3.3 達成確認ダイアログ

- タイトル: 「達成確認」
- 本文: 「『{習慣名}』を達成済みにしますか？」
- 「キャンセル」ボタン: ダイアログを閉じる
- 「達成」ボタン: 習慣を達成済みに更新し、連続日数を+1加算する

## 4. 今後の拡張予定

- 習慣タップ時の詳細画面への遷移
- 習慣の追加・編集・削除機能
- データの永続化（ローカルDB）
- 挨拶メッセージの時間帯別切り替え
