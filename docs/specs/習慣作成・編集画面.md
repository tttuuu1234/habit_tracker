# 習慣作成・編集画面 仕様書

## 1. 概要

習慣作成・編集画面は、新しい習慣の登録および既存の習慣の内容変更を行う画面である。作成と編集で同一の画面レイアウトを共有し、モードに応じてタイトルや初期値が変わる。

主な目的:

- 新しい習慣を登録する
- 既存の習慣の名前・頻度・カラーを変更する
- 不要になった習慣を削除する

## 2. 表示仕様

### 2.1 AppBar

- **タイトル**: 作成モード時「習慣を追加」、編集モード時「習慣を編集」
- **左**: 戻るボタン（←）

### 2.2 習慣名入力欄

- テキストフィールドで習慣名を入力する
- プレースホルダー: 「例: 30分読書」
- 最大30文字。空文字は許可しない（前後の空白はトリムする）

### 2.3 頻度選択

- 「毎日」「曜日指定」の2つのセグメントから選択する
- デフォルトは「毎日」

### 2.4 曜日選択

- 頻度が「曜日指定」の場合のみ表示する
- 「月」「火」「水」「木」「金」「土」「日」の7つのトグルボタンを横並びで表示する
- 複数選択可能。最低1つの曜日を選択する必要がある

### 2.5 カラーパレット

プリセットカラーを円形のボタンで横並び表示する。選択中のカラーにはチェックマークを表示する。

| 色名 | デフォルト |
|------|-----------|
| グリーン | ○（デフォルト選択） |
| ブルー | |
| パープル | |
| オレンジ | |
| レッド | |
| ピンク | |
| ティール | |
| アンバー | |

### 2.6 フォーム下部のボタン

- **保存ボタン**: フォームの最下部に配置する。バリデーション通過時のみ活性
- **「習慣を削除」ボタン**: 保存ボタンの下に赤文字で配置する。編集モード時のみ表示（作成モードでは非表示）

### 2.7 編集モード時の初期値

- 各フィールドに既存の習慣の値を反映して表示する
- 登録日は編集しても変更しない

## 3. ユーザー操作

### 3.1 保存ボタンをタップ

- バリデーションを満たしている場合のみタップ可能
- 作成モード: 習慣を新規保存し、ホーム画面に戻る
- 編集モード: 変更内容を保存し、習慣詳細画面に戻る
- 保存処理中はローディング表示を行い、二重タップを防止する

### 3.2 戻るボタンをタップ

- フォームに変更がない場合: そのまま前の画面に戻る
- フォームに変更がある場合: 破棄確認ダイアログを表示する

### 3.3 破棄確認ダイアログ

- タイトル: 「変更を破棄」
- 本文: 「入力内容が破棄されますがよろしいですか？」
- 「キャンセル」ボタン: ダイアログを閉じ、画面に留まる
- 「破棄」ボタン: 入力内容を破棄して前の画面に戻る

### 3.4 削除ボタンをタップ（編集モードのみ）

- 削除確認ダイアログを表示する

### 3.5 削除確認ダイアログ

- タイトル: 「習慣を削除」
- 本文: 「『{習慣名}』を削除しますか？達成記録もすべて削除されます。」
- 「キャンセル」ボタン: ダイアログを閉じ、画面に留まる
- 「削除」ボタン: 習慣と関連する達成記録を削除し、ホーム画面に戻る

## 4. バリデーションルール

- BR-1: 習慣名は空文字を許可しない（前後の空白はトリムする）
- BR-2: 習慣名は30文字以内とする
- BR-3: 頻度が「曜日指定」の場合、最低1つの曜日を選択しなければ保存できない
- BR-4: カラーは必ず1つ選択されている状態とする（デフォルト: グリーン）
- BR-5: 「保存」ボタンはBR-1〜BR-3のバリデーションを満たさない場合は非活性とする

## 5. 画面遷移

- ホーム画面 → AppBar「+」タップ → 習慣作成画面
- 習慣作成画面 → 保存 → ホーム画面
- 習慣作成画面 → 戻る → ホーム画面（変更時は破棄確認ダイアログ）
- 習慣詳細画面 → AppBar編集ボタンタップ → 習慣編集画面
- 習慣編集画面 → 保存 → 習慣詳細画面
- 習慣編集画面 → 削除 → ホーム画面（削除確認ダイアログを経由）
- 習慣編集画面 → 戻る → 習慣詳細画面（変更時は破棄確認ダイアログ）
