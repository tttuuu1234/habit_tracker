# 習慣詳細画面 仕様書

## 1. 概要

習慣詳細画面はホーム画面から習慣をタップした際に遷移する画面であり、選択した習慣の達成記録を詳しく確認できる。

主な目的:

- 現在の連続達成日数を確認する
- 月単位のカレンダーで達成/未達成の記録を視覚的に把握する
- 最長連続日数や達成率で長期的な達成状況を振り返る

## 2. 表示条件・ルール

### 2.1 連続達成日数

- 今日から遡って途切れずに達成している日数を表示する
- 今日が未達成でも、昨日まで連続していればその日数を表示する
- 一度も達成していない場合は「0」を表示する

### 2.2 月間記録カレンダー

#### セルの表示条件

| 条件 | 表示 |
|------|------|
| 達成済みの日 | 緑で塗りつぶし |
| 未達成の日（過去・今日） | グレーで塗りつぶし |
| 未来の日 | 破線の枠のみ（塗りつぶしなし） |
| 習慣登録日より前の日 | 表示しない（空白セル） |

- 画面を開いた時点では当月のカレンダーを表示する

#### 月移動ボタンの活性・非活性条件

| ボタン | 活性条件 | 非活性条件 |
|--------|---------|-----------|
| ← (前月) | 前月に習慣登録日以降の日が含まれる | 表示中の月に習慣登録日が含まれる（これ以上戻れない） |
| → (翌月) | 表示中の月が当月より前 | 表示中の月が当月（これ以上進めない） |

### 2.3 統計カード

- **最長連続**: 習慣登録日から今日までの全期間で、最も長く連続して達成した日数を表示する
- **達成率**: `達成した日数 ÷ (習慣登録日から今日までの日数) × 100` をパーセント表示する（小数点以下は切り捨て）

## 3. ユーザー操作

### 3.1 戻るボタン

- ホーム画面に戻る

### 3.2 AppBar右上の編集ボタンをタップ

- 習慣編集画面へ遷移する

### 3.3 月移動ボタン

- 「←」をタップすると前月のカレンダーに切り替わる
- 「→」をタップすると翌月のカレンダーに切り替わる
- 非活性状態のボタンはタップできない

## 4. 画面遷移

- ホーム画面 → 習慣タップ → 習慣詳細画面
- 習慣詳細画面 → 編集ボタン → 習慣編集画面
- 習慣詳細画面 → 戻るボタン → ホーム画面
